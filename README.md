# QRFood

Sistema web de cardápio digital com QR Code desenvolvido para a disciplina de Programação Orientada a Objetos da Fatec Praia Grande.

## Objetivo

Permitir que restaurantes, lanchonetes e vendedores organizem seus produtos digitalmente, oferecendo aos clientes acesso rápido ao cardápio por QR Code e possibilidade de realizar pedidos pelo celular.

## Funcionalidades

* Cadastro e login de administrador
* Cadastro de produtos
* Upload de imagens
* Geração de QR Code
* Cardápio online responsivo
* Carrinho de compras
* Envio de pedidos
* Controle de status do pedido

## Tecnologias

* Java
* Spring Boot
* MySQL
* HTML/CSS/JavaScript
* Bootstrap

## Público-alvo

* Carrinhos de lanche
* Pequenos restaurantes
* Hamburguerias
* Lojas de alimentos
